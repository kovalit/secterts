Коллекции

Коллекция — это набор однотипных элементов с общей схемой. Она описывает структуру данных: какие поля есть у элемента, какого они типа и какие из них обязательны. У одного сайта может быть несколько коллекций.

Обновлено 24 сентября 2026 6 минут на чтение

Обзор

Через API коллекций можно создавать, читать и удалять коллекции, а также управлять их полями. Все запросы выполняются от имени токена с правами cms:write или cms:read.

  • Схема задаётся массивом fields и применяется ко всем элементам коллекции.
  • Слаг используется в URL страниц сайта и должен быть уникальным в пределах сайта.
  • Системные поля создаются автоматически и присутствуют в каждой коллекции.

Перед началом

Получите токен доступа в разделе Аутентификация и сохраните его в переменной окружения ORBITA_TOKEN. Все примеры ниже используют её.

Модель коллекции

Объект коллекции, который возвращают все методы этого раздела.

ПолеТипОписание
idObjectIdУникальный идентификатор коллекции
displayNameStringНазвание коллекции в интерфейсе редактора
singularNameStringНазвание одного элемента, например «Статья» для коллекции «Статьи»
slugStringЧасть URL, по которой открываются элементы коллекции на сайте
createdOnDateДата создания в формате ISO 8601
lastUpdatedDateДата последнего изменения схемы или настроек
fieldsArray<Field>Список полей коллекции. Подробнее о полях →

Создание коллекции

Создаёт новую коллекцию на указанном сайте. Поле name добавляется автоматически, остальные поля можно добавить позже.

POST /v2/sites/{site_id}/collections

Пример запроса 

curl -X POST https://api.orbita.dev/v2/sites/$SITE_ID/collections \
  -H "Authorization: Bearer $ORBITA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "displayName": "Статьи блога",
    "singularName": "Статья",
    "slug": "posts"
  }'
import { Orbita } from '@orbita/sdk'

const client = new Orbita({ token: process.env.ORBITA_TOKEN })

// Создаём коллекцию на выбранном сайте
const collection = await client.collections.create(siteId, {
  displayName: 'Статьи блога',
  singularName: 'Статья',
  slug: 'posts',
})

console.log(collection.id) // "7f62a9781291109b9e428fb47239fd35"
import os
from orbita import Orbita

client = Orbita(token=os.environ["ORBITA_TOKEN"])

# Создаём коллекцию на выбранном сайте
collection = client.collections.create(
    site_id,
    display_name="Статьи блога",
    singular_name="Статья",
    slug="posts",
)

Параметры запроса

ПараметрТипОписание
site_idобязательный · path ObjectId Идентификатор сайта, в котором создаётся коллекция
displayNameобязательный String Название коллекции, от 1 до 64 символов
singularNameобязательный String Название одного элемента коллекции
slugнеобязательный String Латиница, цифры и дефис. По умолчанию генерируется из displayName.
fieldsнеобязательный Array<Field> Поля, которые нужно создать сразу вместе с коллекцией

Слаг нельзя изменить после публикации

Если у коллекции есть опубликованные элементы, изменение slug сломает существующие ссылки. Выбирайте слаг заранее.

В случае успеха API возвращает созданную коллекцию со статусом 201 Created.

Системные поля

Каждая коллекция содержит служебные поля. Часть из них можно менять через API, остальные управляются платформой.

ПолеТипИзменяемоеОписание
_archivedBooltrueАрхивные элементы не публикуются на сайте
_draftBooltrueЧерновики видны только в редакторе
_cidObjectIdfalseСсылка на коллекцию, которой принадлежит элемент
_publishedOnDatefalseДата последней публикации элемента

Коды ошибок

Ошибки возвращаются в едином формате с полями code и message.

СтатусКодКогда возникает
400validation_errorТело запроса не прошло валидацию. Подробности — в поле details
401unauthorizedТокен отсутствует, истёк или отозван
409slug_conflictКоллекция с таким слагом уже существует на сайте
429rate_limitedПревышен лимит запросов. Повторите после паузы из заголовка Retry-After

Удаление коллекции необратимо

Вместе с коллекцией удаляются все её элементы и история изменений. Восстановить данные после удаления нельзя.

Перед удалением выгрузите данные через экспорт.
